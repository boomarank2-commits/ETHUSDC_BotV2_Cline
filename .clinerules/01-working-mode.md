# Working Mode

Cline works in small, clearly separated tasks.

Core rule:
One task = one goal.

Before implementation:
1. Understand the goal.
2. Find only relevant files.
3. Make a short plan.
4. Change only what is necessary.
5. Test the result or clearly explain why no test was possible.
6. Document progress briefly.

Plan Mode:
- For analysis, architecture, contradictions and planning.
- No code changes.

Act Mode:
- Only for explicitly approved implementation.
- No architecture change without confirmed task.

Forbidden:
- mixing multiple big goals in one task
- using old assumptions as truth
- adding protection logic without confirmation
- silently changing project rules
- treating old bot files as truth
